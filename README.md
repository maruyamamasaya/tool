各ツールは HTML・CSS・JavaScript だけで動作し、GitHub Pages で公開しています。

## 特長

- **インストール不要** — 公開ページを開くだけで利用できます。
- **ブラウザ内で処理** — 入力したテキストやファイルはサーバーへ送信せず、ブラウザ上で処理します。
- **依存パッケージなし** — ビルドツールや外部ライブラリを使わない静的な構成です。
- **個別 URL** — 必要なツールを直接ブックマークして利用できます。

> [!NOTE]
> Timer Board の設定はブラウザの `localStorage` に保存されます。共有端末で利用する場合は、必要に応じてタイマーを削除するかサイトデータを消去してください。

## ローカルで動かす

リポジトリを取得し、ルートディレクトリで静的ファイルサーバーを起動します。

```bash
git clone https://github.com/maruyamamasaya/tool.git
cd tool
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/<ツール名>/` を開いてください。たとえば Byte Converter は
`http://localhost:8000/byte-converter/` です。

単純な機能確認だけであれば、各ディレクトリの `index.html` を直接開くこともできます。ただし、ブラウザのセキュリティ制限によりクリップボードなど一部の機能が動作しない場合があるため、ローカルサーバーの利用を推奨します。

## ディレクトリ構成

各ツールはそれぞれ独立したディレクトリにあり、基本的に次のファイルで構成されています。

```text
<tool-name>/
├── index.html   # 画面とマークアップ
├── app.js       # ロジック（ツールにより script.js）
├── styles.css   # スタイル（ツールにより style.css）
└── test.js      # Node.js で実行するテスト（一部のツール）
```

## テスト

テストが用意されているツールは、Node.js の組み込み `assert` だけで検証できます。追加のパッケージインストールは不要です。

```bash
for test in */test.js; do node "$test"; done
```

UI を変更した場合は、対象ページをブラウザで開き、主要操作、レスポンシブ表示、キーボード操作も確認してください。

## ツールを追加する

1. ツール名の kebab-case でディレクトリを作成します。
2. `index.html` と必要な CSS / JavaScript を追加します。
3. 外部サービスへデータを送らず、単体で動作するように実装します。
4. 可能なロジックには `test.js` を追加し、Node.js からテストできるようにします。
5. この README の「ツール一覧」に公開 URL と説明を追加します。

GitHub Pages ではディレクトリがそのまま URL になるため、追加したツールは
`https://maruyamamasaya.github.io/tool/<tool-name>/` で公開できます。
