# Audio Check 追加

## 調査

- 静的な個別ツール構成、ルート一覧、README、Node.js `assert` テストの登録方法を確認した。
- Web Audio API は左右の定位と確認音をブラウザ内で生成できる。
- 出力デバイス名、現在の出力先、物理的な接続方式はブラウザと権限によって取得範囲が異なる。

## 変更

- `audio-check/` を追加し、左、右、左→右→両方のステレオ確認音、音量調整、停止を実装した。
- MediaDevices API で取得可能な出力先一覧と件数、出力切替対応、サンプルレートを表示するようにした。
- ルート一覧と README に Audio Check を登録し、件数を同期した。

## 検証

- `audio-check/test.js`、`site.test.js`、全 Node.js テストが成功した。
- ローカル HTTP サーバー上でデスクトップ幅と 500px 幅を描画し、レイアウトとデバイス情報取得失敗時の表示を確認した。

## 未解決事項

- OS・ブラウザの制約により、端子／Bluetooth などの接続方式や、デバイス名を取得できない環境がある。画面上で制約を明記した。
