# トップページの表示形式切り替え

## 調査

- ルート一覧は `index.html` のカードマークアップを `site.js` がカテゴリ・お気に入り単位で制御し、`site.css` がレスポンシブ表示を担う。
- 既存の表示設定とお気に入りは `localStorage` に保存されている。

## 変更

- ツール一覧見出しに「カード」「リンク一覧」の表示切り替えを追加した。
- リンク一覧ではアイコンとカード装飾を省き、ツール名と説明をコンパクトに表示する。
- 選択した表示形式を `browserToolsViewMode` に保存し、再読み込み後も復元する。
- 狭い画面では名前と説明を縦に並べる。

## 検証

- `node site.test.js` が成功した。
- ローカル HTTP サーバー上でボタン操作、再読み込み後の保持、Tab / Enter による切り替えを確認した。
- デスクトップ幅の表示を目視し、狭い画面向けの CSS ルールを確認した。
