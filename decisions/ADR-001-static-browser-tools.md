# ADR-001: 静的・ブラウザ内完結を基本とする

## Context

README は本サイトをインストール不要の GitHub Pages 向けツール集とし、入力をサーバーへ送らず、HTML / CSS / JavaScript だけで動かす方針を明記している。Git 履歴でも初期のファイル配置修正（`752040b`）以降、ツールごとの静的ディレクトリが継続して追加されている。

## Decision

- 個別ツールは GitHub Pages から直接配信できる静的ファイルとして実装する。
- 入力データの処理は原則として利用者のブラウザ内で完結させる。
- 各ツールは独立 URL を持ち、実行にサーバー、DB、インストール、ビルドを要求しない。
- 外部送信や実行時依存が必要な変更は暗黙に追加せず、プライバシー、可用性、代替案を確認して文書化する。

## Consequences

- GitHub Pages と単純なローカル HTTP サーバーで動作し、利用者データをサーバー側に保持しない。
- 永続化は `localStorage` やファイル export に限定され、端末間同期やサーバー側バックアップはない。
- 重複コードが生じ得る一方、あるツールの変更や障害が他ツールへ波及しにくい。
- サーバーを必要とする機能や秘匿情報を伴う API 連携は、この決定の再検討なしには追加できない。

## Confirmed exception

2026-08-28 時点で YAML Viewer は jsDelivr の `js-yaml@4.1.0` に依存する。採用理由は確認できないため、本 ADR が外部依存全般を禁止したという意味にはせず、解消または例外承認を [CURRENT.md](../CURRENT.md) の未解決事項として扱う。
